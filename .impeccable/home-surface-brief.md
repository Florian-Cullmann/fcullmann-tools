# Public home

- Scope: localized public homepage at `/en` and `/de`; mode: Persuade with an embedded Operate moment.
- Audience and job: developers seeking a useful browser tool, and technical peers or collaborators evaluating Florian's work.
- Primary action: use the JSON formatter immediately or continue into the tool catalogue.
- Proof and content: a working local formatter, ranked featured tools, selected projects, and technical writing. Personal claims remain placeholders until supplied.
- Constraints: English first with a persisted German alternative; WCAG 2.2 AA; fast and indexable; no account needed; administration is separate.
- Chosen direction: API Atlas — technical atlases, RFC diagrams, and field-navigation charts become functional wayfinding across one professional software territory. Approved composition: `.impeccable/mocks/decision/api-atlas.webp` (Atlas Workbench).
- Memorable moment: a vermilion route leaves Florian's map legend and opens directly into a working JSON input-to-output path.
- Unresolved: verified biography, project records, portrait, social URLs, and legal details.
